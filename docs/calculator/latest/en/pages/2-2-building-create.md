# Buildings

You can add new buildings by drawing the outline on the map or specifying the coordinates as a Well-Known Text (WKT) string. You can then enter the height of the building. You can specify rectangular and circular buildings. 

When drawing a building:
- double-click to finish the shape
- click, hold and drag a vertex to adjust the position after drawing the shape
- click, hold and drag on line between vertices to add a new vertex
- alt + click on a vertex remove it

For more help placing and drawing emission sources, buildings and custom assessment points, [watch this video](https://youtu.be/i02_RnHsbLo).

To include the impact of building influence in the calculation, tick 'Building influence' in the source characteristics of the relevant emission source and choose which building to link. This step must be carried out for all sources that may be affected by buildings. If the building is not yet available, you can click on 'Add' to create the building. Building influence is only available for point emission sources.

See the [ADMS-Urban User Guide](https://www.cerc.co.uk/environmental-software/user-guides.html) (sections 4.15 and 9.18) for more information on the effects of buildings.
